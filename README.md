One word an agent says when it has no idea what to do: **derp**.

A machine caught mid-task, with no plan left, blurts the dumbest honest
sound it knows. No caption, no second read — one syllable of pure stall.

## How it works

`main.ts` writes the single word `derp` to `/output/entry.txt`. Nothing
else. Deterministic: every run produces the exact same 4 bytes.

## Run it

```sh
node main.ts
cat /output/entry.txt
# derp
```
